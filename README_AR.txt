ملفات صفحات الخصوصية للعبة مغامرة السلم والثعبان

المحتويات:
- index.html
- privacy.html
- data-deletion.html
- style.css

النشر:
1) ارفع الملفات الأربعة إلى مشروع استضافة صفحات ثابتة (مثل Replit أو GitHub Pages).
2) انشر المشروع واجعله عامًا عبر HTTPS.
3) انسخ الرابط العام لصفحة privacy.html إلى حقل سياسة الخصوصية في Meta.
4) انسخ الرابط العام لصفحة data-deletion.html إلى حقل حذف بيانات المستخدم في Meta.

تنبيه مهم:
هذه صياغة أولية. قبل النشر، راجع بنود البيانات واجعلها مطابقة تمامًا لما تجمعه اللعبة فعليًا، وخدمات تسجيل الدخول والاستضافة والتحليلات والإعلانات المستخدمة. لا تضع روابط محلية أو روابط غير منشورة في إعدادات Meta.
